# Website webfonts

This directory contains only the webfont files currently referenced by the website. They are self-hosted and loaded from this repository; no external font CDN is required.

| Family | Included file(s) | Site usage |
|---|---|---|
| Inter | `InterVariable.woff2` | English interface and controls |
| Lora | `Lora[wght].woff2` | English story prose |
| Cormorant Garamond | `CormorantGaramond-Light.woff2`, `Regular`, `Medium`, `SemiBold`, `Bold`, `Italic` | English display headings |
| Cascadia Code | `CascadiaCode.woff2` | Code samples and IPA |
| Vazirmatn | `Vazirmatn.woff2` | Persian interface and text |
