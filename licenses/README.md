## Maintenance rules

1. When adding or replacing a font, verify its license and copyright notice from the font's upstream project.
2. Keep the complete license text and copyright attribution with the distributed font files.
3. Do not sell OFL font software by itself or relicense it under different terms.
4. Before modifying or converting font files, review the OFL conditions and the OFL FAQ—especially the rules for Reserved Font Names and WOFF/WOFF2 conversion.
5. Keep this index, [`fonts/README.md`](../fonts/README.md), and [`THIRD-PARTY-NOTICES.md`](../THIRD-PARTY-NOTICES.md) synchronized with the actual files in `fonts/`.

The font licenses cover font software only. They do not determine the license of the website, story, or other original repository content.

See the [SIL Open Font License](https://openfontlicense.org/) for the license and FAQ.
