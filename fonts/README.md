# Website webfonts

Only the webfont files used by the website are kept in this directory.

| Family | File(s) | Purpose |
|---|---|---|
| Inter | `InterVariable.woff2` | English interface and controls |
| Lora | `Lora[wght].woff2` | English story text |
| Cormorant Garamond | `CormorantGaramond-{Light,Regular,Medium,SemiBold,Bold,Italic}.woff2` | English display headings |
| Cascadia Code | `CascadiaCode.woff2` | Code samples and IPA |
| Vazirmatn | `Vazirmatn.woff2` | Persian interface and story text |

All fonts are self-hosted. No external font CDN is required.
